\section{Medidas descriptivas (media, cuartiles, etc.)}

Para una variable $x_1,\dots,x_n$:

\begin{itemize}
    \item \textbf{Media:} $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$
    \item \textbf{Mediana:}
    \begin{itemize}
        \item Ordenar los datos.
        \item Si $n$ es impar: posición $\frac{n+1}{2}$
        \item Si $n$ es par: promedio entre las posiciones $\frac{n}{2}$ y $\frac{n}{2}+1$
    \end{itemize}
    \item \textbf{Q1 y Q3:} se calculan sobre datos ordenados (\textit{aclarar el criterio que usan, porque hay varios}).
    \item \textbf{Rango Intercuartílico (RI):} $RI = Q3 - Q1$
\end{itemize}

La diferencia entre los valores de los cuartiles calculados de forma manual y los
obtenidos mediante las herramientas de Python radica en que, cuando se lleva a cabo
manualmente, se realiza con el método original. Por otro lado, al hacerlo con Python
las librerías automáticamente realizan una interpolación entre las muestras, causando
que el cuartil 3 (y todos los valores derivados del cuartil 3) se vean modificados levemente.
