\subsection*{b) Resolución manual mediante el algoritmo PRISM}

El algoritmo PRISM construye un conjunto de reglas modular evaluando cada clase objetivo por separado. En cada iteración, se busca la condición que minimice el error de clasificación (calculado como la proporción de falsos positivos sobre el total de instancias que cumplen la condición). Una vez alcanzado un error de $0$, la regla se consolida, se eliminan del conjunto de datos las instancias cubiertas por ella y se repite el proceso hasta cubrir todos los casos de la clase analizada.

Nuevamente, el desarrollo manual puede encontrarse en su anexo correspondiente.

\subsection*{c) Resultado del algoritmo comenzando por la clase \texttt{Inflado = no}}

En caso de comenzar por la clase "No Inflado", las reglas resultado serían las mismas pero cambiaría el orden en el que las evaluamos. Como se evalúan las clases por separado, el conjunto de datos de entrenamiento se reinicia cuando cambiamos el objetivo, retornando los mismos errores para las mismas reglas.
